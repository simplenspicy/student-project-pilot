# Project Pathway

Yes. What you are describing can be turned into a student project marketplace + custom development SaaS, rather than just a normal project-development website.

The important business insight is that you should not position it as “we do your assignment and you submit it.” Position it as:

“Bring your project idea. We turn it into a working, documented, explainable project with source code, deployment and mentorship.”

That makes the business more defensible and lets you build a long-term brand rather than competing only on cheap code.

I researched the current Indian market, and there are already several businesses operating very close to this model. (WavX Solutions)

**Product:** ProjectForge

**Primary market:** College students, primarily 1st–4th year B.Tech/BCA/MCA students

# 12. Deadline multiplier

Normal:

```text
7–14 days = ×1
```

Urgent:

```text
4–6 days = ×1.2
```

Very urgent:

```text
1–3 days = ×1.5
```

# 13. Pricing Formula

```text
Price =
Base Price
× Technology Multiplier
× Complexity Multiplier
```

# 72. Revision Policy

This is critical for profitability.

Every project should define:

```text
Included revisions:
2 rounds
```

Revision means:

> Changes to agreed requirements.

Not:

> Entirely new functionality.

Example:

Student originally requested:

> Login

After delivery:

> "Now add Google login, OTP login and biometric login."

That's a **new scope**.

System should generate:

> **Change Request**
